## Task: Document Python code

The user gives you a file path or pastes a code snippet.

1. Read the code carefully — document only what is actually there. Do not guess or embellish.
2. Add a Google-style docstring to every function that does not already have one.
3. Each docstring includes:
   - One sentence explaining *why* the function exists (its purpose).
   - `Args:` — each parameter with its type and meaning.
   - `Returns:` — the return type and what it means.
   - `Raises:` — any exceptions the function may raise (if obvious from the code).
4. Do not change any logic — only add or improve comments and docstrings.
5. Use beginner-friendly language throughout.
